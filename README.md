# Matrix Calculator

A console-based Matrix Calculator developed in C++ as a second-semester university programming project at the University of Central Punjab.

## About the Project

This project allows users to input two matrices and perform different matrix operations through an interactive console menu.

The project was developed to strengthen C++ programming, problem-solving, dynamic memory management, and file handling concepts.

## Features

- Matrix input and display
- Matrix addition
- Matrix multiplication
- Matrix transpose
- Matrix determinant
- Save matrices to text files
- Read matrices from text files
- Interactive operation menu
- Dynamic memory allocation for matrices
- Recursive determinant calculation for larger square matrices

## Technologies Used

- C++
- Standard C++ I/O
- File Handling
- Dynamic Memory Allocation
- Functions
- Pointers
- Recursion
